brisk

buildpassingreleasev0.9.2licenseMITdownloads41k/week

Fast, open source test selection. brisk reads your project's import graph and runs only the tests your change touches, so CI takes seconds instead of minutes.

Install

brew install brisk-dev/tap/brisk
# or, in a JavaScript project
npm install --save-dev brisk

Usage

brisk run --since main

brisk 0.9.2 · 3 files changed since main
  selected  12 of 1,284 tests
  ✓ 12 passed in 2.1s

How it works

  1. brisk builds an import graph of your project once and caches it.
  2. Each run finds the files your change touched and walks the graph to every test that imports them.
  3. It hands those tests to your runner: Vitest, Jest, pytest, or cargo test.
