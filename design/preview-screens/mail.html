This week's pick
brisk
Run only the tests your change touches.

The open source tool everyone shared this week reads your project's import graph and runs only the tests a change touches. It went from a tweet to 8,400 stars in four days, and teams in the replies report CI going from minutes to seconds.

It works with Vitest, Jest, pytest, and cargo test, caches the graph between runs, and installs with one command. Read the announcement →
